# LabSpotter demo

A static walkthrough page for LabSpotter: UI captures, the eight action classes, and the demo video.

The project itself (source, documentation, run and test guides) lives at [nxtkim-1/labspotter-public](https://github.com/nxtkim-1/labspotter-public).

## Files

| File | Purpose |
| --- | --- |
| `index.html` | The walkthrough page. No build step; open it in a browser. |
| `2-walkthrough.mp4`, `3-walkthrough_poster.png` | Demo video and its poster frame |
| `1-`, `2-`, `4-`, `5-*.png` | UI captures used on the page |
| `9-` to `16-*.jpg` | One still per action class: Add, Analytical Measurement, Collect Layer, Measure Liquid, Measure Solid, No action, Phase Separation, Stir |
| `6-`, `7-`, `8-*` | Fonts used by the page (Space Grotesk, IBM Plex Mono, Inter) |

This repository is presentation only; there is no application code here.
